# Reference — Admin Profile

**Path:** Admin → Admin Profile (or click Profile in settings sidebar)

The Admin Profile screen allows logged-in administrators and operations staff to manage their personal details and enforce multi-factor account security.

---

## Profile Management Sections

### 1. Account Overview
Displays your username, email address, role (Administrator or Field Service), and profile initial avatar badge.

### 2. Personal Information
Modify your display name, login email, and contact phone number. Click **Save Profile** to update your account database record.

### 3. Change Password
To update your password:
1. Enter your **Current Password**.
2. Enter your **New Password** (minimum 6 characters).
3. Re-type it in **Confirm New Password**.
4. Click **Change Password** to update.

---

## Account Security (MFA / 2FA)

Multi-Factor Authentication (MFA) protects your administrative account from unauthorized login attempts.

### Setting Up Two-Factor Authentication
1. Click **Set up 2FA** to generate your unique authenticator key.
2. Open a standard Authenticator application (e.g. Google Authenticator, Microsoft Authenticator, or Bitwarden) on your smartphone.
3. Scan the displayed QR code or enter the secret key text manually.
4. Input the current 6-digit verification code generated by the app.
5. Click **Verify and Enable 2FA**. The account is now protected and requires a code on next login.
