# Ace Tours User Manual — v1.0.0

First release of the manager's user manual. PDF attached below.

## What's in v1.0.0

- **3 introduction chapters**: cover, introduction (who/how/why), getting started
- **10 workflow chapters** covering: taking bookings, cancellations/refunds,
  blackouts, capacity, CMS, pricing/promotions, products, reports, staff/user
  access, audit logs
- **21 screen-by-screen reference pages** covering every admin screen
- 105 pages, A4

## Known limitations

- No screenshots embedded in this release — coming in v1.1
- Some chapter frontmatter uses conceptual role names (`owner`, `operator`)
  alongside the canonical codebase roles (`admin`, `field_service`). Reconciliation
  scheduled for v1.1.

## How to view

Download `Ace-Tours-User-Manual-v1.0.0.pdf` from the assets below. Open in any
PDF viewer. Use `Ctrl+F` / `Cmd+F` to search.

## How it's built

Source is Markdown under `docs/user-manual/` in this repo. Build with:

```bash
npm run docs:manual:build
```

See `docs/user-manual/README.md` for full editing and release instructions.
